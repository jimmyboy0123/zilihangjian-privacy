《字里行间》隐私政策

最后更新日期：2026-10-30

《字里行间》是一款在本机使用的文化创作应用。本说明只描述当前 iOS 版本的真实行为，供 TestFlight 测试与后续上架使用。

一、我们是谁

本应用由字里行间开发者提供。测试阶段没有独立用户账号，也没有把你的作品自动同步到开发者服务器。

二、哪些数据只留在你的设备

以下内容默认写在本机沙盒、系统钥匙串或你自己导出的文件里：

  • 文化种子库的安装副本，以及你之后新增的故事、档案、计划、作品
  • 字帖、切字、集字、实体图片、配音与导出成片
  • 通讯录及其中的照片（仅你主动使用通讯录时）
  • 大模型与 AI 生图的 API Key（系统钥匙串；极少数情况下才落到本机加密文件）
  • 外观、语言、罗盘背景等偏好

完整备份由你在「媒体中心」手动导出。备份默认不包含 API Key、通讯录照片和调试状态。Key 如需换机，只能由你设密码后单独导出加密设置包。

三、哪些数据会离开本机

应用没有内置统计分析、广告或崩溃上报 SDK。但只要你使用下列功能，相关内容就会发往第三方或你自己填写的地址：

  1. 大模型对话、故事生成、绘境提示词
    发往你在设置里选择的 DeepSeek 或阿里云百炼。内容包括提示词、故事设定和模型返回的文本。
  2. AI 生图
    发往火山方舟（Seedream）。内容包括生图提示词及服务商返回的图片。
  3. 配音
    使用阿里云百炼 CosyVoice。内容包括待朗读的文本。
  4. 「感兴趣」网络热搜
    会向公开热榜来源（如微博、百度等）请求话题列表；若你同时启用了大模型，应用可能再用这些话题去匹配文化实体。
  5. 切图服务 / 云端主站
    仅当你自己填写了服务地址时才会访问。切图会上传你选择的页面图片。正式版本不会把 API Key 同步到云端主站。
  6. 你主动分享或保存到系统相册、文件的内容
    按 iOS 系统机制处理。

没有配置 API Key 时，查字、字帖阅读、典藏浏览和本地切字等功能仍可使用，不会因此去调用上述 AI 接口。

四、第三方如何处理数据

下列服务仅在你主动使用对应功能、并（如需）自行填写 API Key 时才会接到数据。字里行间不能控制这些服务如何存储或训练模型。请只使用你自己的 API Key，并在对方控制台自行设置额度。

  • DeepSeek：对话 / 故事 / 绘境
  • 阿里云百炼（DashScope / CosyVoice）：对话与配音
  • 火山方舟（Seedream）：AI 生图
  • 公开热榜来源（如微博、百度等）：仅请求公开话题列表

请以各服务商官网现行隐私政策与计费规则为准。本页不代替对方的政策文本。

五、权限

仅在对应功能需要时向系统申请：

  • 相机：拍摄字帖图片并上传切图
  • 相册读取：选择图片或影片，收入字帖、分镜参考等
  • 相册写入：将探索成片保存到相册
  • 麦克风：在字帖再现过程中录制讲解或诵读
  • 面容 / 本机解锁：打开通讯录收藏的人，或填写、重设设置迁移密码
  • 本地网络：连接你本机或局域网内的字里行间服务（可选）

拒绝某项权限只会关闭对应功能，不影响其他本地功能。

六、如何处理或删除数据

本应用没有开发者侧用户账号，因此也没有「向我们申请删除云端作品」的流程。

  • 可在应用内删除故事、计划、字帖等条目，或在「媒体中心」管理本机文件。
  • 可在设置中清除自行填写的 API Key。
  • 卸载应用会删除本机沙盒中的作品与设置副本。若卸载前未先在设置中清除 Key，系统钥匙串里可能仍留有密钥，可在重装后进入设置再清除。
  • 已经发往 DeepSeek、阿里云百炼、火山方舟等第三方的内容，无法由本应用代为删除，需按对方政策处理。

七、我们不做什么

  • 不建立测试者账号，也不查看你设备里的作品
  • 不把开发者个人 API Key 打包进应用
  • 不在正式版本提供开发模式、局域网调试或数据资产管理后台
  • 不声称「所有数据永远只在本地」——一旦使用 AI 或你填写的外部地址，数据就会离开本机

八、儿童

本应用面向成人文化创作，不面向 13 岁以下儿童收集个人信息。

九、联系与更新

测试阶段如有隐私问题，请直接联系邀请你加入 TestFlight 的开发者。本页不公布个人邮箱。

政策更新后，会同步修改应用内「设置 → 隐私政策」与本页。若将来绑定自有域名，本页内容保持同一份。
